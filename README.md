# Employee Management Application

A responsive Employee Management Application developed using React, Redux Toolkit, Bootstrap, and REST API integration.

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- Axios
- Bootstrap
- Vitest
- React Testing Library
- JavaScript
- REST API

## Features

- Display employee list
- Search employee by ID
- Add new employee
- Edit employee
- Delete employee with confirmation
- Pre-filled form while editing
- Form validation
- Loading state
- Error state
- Empty/search not-found state
- Responsive design
- Redux Toolkit state management
- REST API integration
- Unit testing

## Employee Form Fields

- Name
- Email
- Mobile
- Country
- State
- District

## Validation

- Required field validation
- Email format validation
- Mobile number validation
- Name length validation
- Email length validation
